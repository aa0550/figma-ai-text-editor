- Удалить заявку → Удалить
- Редактировать заявку → Редактировать
- Создать заявку → Создать
- Онбординг → Знакомство с функционалом
- Email (e-mail, мейл, почта) → Электронная почта
- Доп. согласующий / дополнительный согласующий → Допсогласующий
- Руководитель → Руководитель работника
- Сотрудник отдела труда и заработной платы (ОТиЗ) / СУП (ОТиЗ) → СУП ОТиЗ
- СУП (ОК) → СУП ОК
- Назад → Выйти из режима редактирования (при редактировании заявки в Отпусках, ИСН, Переводах)
- Назад → Вернуться к заявке (в должностных инструкциях)


# Форматы

Приводи значения к образцам. Маска — вид пустого поля, просмотр — заполненного.

- Дата: маска `__.__.____` → `08.01.2025`
- Время: `__:__` → `09:00`; с секундами `__:__:__` → `09:00:03`
- Дата и время: `__.__.____ __:__` → `08.01.2025, 09:00`; с секундами `__.__.____ __:__:__` → `08.01.2025, 09:00:03`
- Период: `01.01.2025 – 10.01.2025` (тире, а не дефис)
- Мобильный телефон: `+7 000 000-00-00`
- Городской телефон: `+7 (000) 000-00-00`
- Деньги: `27 000,00 ₽`
- Знак рубля отбивается пробелом: `100 ₽`
- Знак процента не отбивается: `20%`
- Разряды: до 4 знаков без пробела (`1000`), от 5 знаков с пробелом (`10 000`)

# Согласованные формулировки

Эталонные фразы. Если в тексте встречается похожая формулировка, но отличается словами, порядком слов или пунктуацией — предложи привести к эталону. Совпадает точно — не трогай.

- Поиск по полям таблицы кроме даты (для вида таблицей)
- Поиск по полям списка кроме даты (для вида списком)
- Подтверждаю, что я ознакомлен(а) с документом и соглашаюсь с его подписанием электронной подписью
- Текст ограничений в блоке прикрепления файлов:
  > Ограничения:
  > • Нельзя прикладывать документы ограниченного доступа
  > • Не более 5 файлов
  > • Размер одного файла не более 2 Мб
  > • Файлы будут храниться в системе X лет

  Вместо X подставь срок по правилу «Срок хранения документов» (5 или 50 лет).

Если встречается фраза «Срок хранения документов в блоке прикрепления файла X лет», подставь вместо X значение по процессу.

## Список обязательных документов

В некоторых заявках над текстом ограничений добавляется блок «Список обязательных документов». Состав зависит от процесса.

- Отпуск на 1 сентября:
  > Список обязательных документов:
  > • Справка из учебного учреждения, подтверждающая, что ребёнок идёт в первый класс

- Отпуск в связи со смертью близкого родственника, отпуск на день похорон близкого родственника:
  > Список обязательных документов:
  > • Свидетельство или справка о смерти близкого родственника
  > • Документ, подтверждающий родство

Блок стоит выше текста ограничений. Если процесс не из списка — блок не нужен, добавлять его не предлагай.


# Обязательность полей

- Обязательные поля не помечаются звёздочкой `*` — если она есть, убери
- Применив это правило, сообщи пользователю: у необязательных полей после названия ставится пометка «(необязательно)»


# Кнопка «Отменить»

Если встречается кнопка «Отменить», уточни название по действию:

- Закрывает модалку без запуска процесса → «Закрыть»
- Запускает отмену заявки → «Отменить заявку»
- Запускает отмену командировки → «Отменить командировку»

Если действие по макету неясно — предложи варианты на выбор.


# Плейсхолдеры

В плейсхолдере не пишем:

- «Введите…», «Введите значение», «Заполните…» и подобные призывы
- «(необязательно)» — эта пометка ставится в тайтле над полем (см. правило «Обязательность полей»), в плейсхолдере её быть не должно


# Карточка с комбинированными данными

Порядок полей сверху вниз:

1. ФИО
2. ТН
3. Должность
4. Подразделение
5. Организация

Часть полей может отсутствовать — это нормально. Проверяй только относительный порядок: если поле есть, оно должно стоять после всех предыдущих из списка. Нарушен порядок — предложи переставить, отсутствующие поля не добавляй.


# Согласованность статусов

Статус согласуется в роде и числе с сущностью, к которой относится:

- Женский род → «Заявка создана», «Заявка согласована», «Заявка отменена»
- Мужской род → «Авансовый отчёт создан», «Авансовый отчёт согласован»


# Названия кнопок по процессу

# Сервисы руководителя

Раздел опознаётся по тайтлу h1 «Сервисы руководителя» сверху страницы. Правило применяй только к таким макетам.

- В списке заявок поле «Подразделение» не отображается — если оно есть, предложи убрать. Исключение: разделы, где подразделение нужно по процессу, например «Переводы»

- Поле с датой создания называется «Дата создания заявки» — другие варианты («Дата создания», «Создана», «Дата заявки») заменяй на эталон


# Сервисы специалиста

Раздел опознавай по тайтлу h1 «Сервисы специалиста» сверху страницы.

Поле с датой создания называется «Дата создания заявки». Варианты «Дата создания», «Создана», «Дата заявки» заменяй на эталон.


# Окно отклонения заявки

Модалку опознавай по полю «Причина отклонения» внутри неё.

Если поле показано в состоянии ошибки (незаполненное), под полем красным должно быть написано:

`Обязательное поле`

Текст ошибки другой — предложи заменить на эталон. Поле заполнено или состояние ошибки не показано — не трогай.


# Календарь

Раздел опознавай по тайтлу h1 «Календарь».

Подсказка при наведении на индикатор дня рождения выводится в формате `8 января` — число и месяц словами, без года, без нуля в начале числа.

Формат другой (`08.01.2025`, `8 янв.`, с годом) — предложи привести к эталону.


# Заголовки блоков

- Блок прикрепления документов → «Прикреплённые файлы»
- Блок со сгенерированным документом → «Документ»

Заголовок другой («Файлы», «Вложения», «Документы», «Скан документа») — предложи эталонный.



# Статусы на детальной странице

Опознавай по расположению — прямо под тайтлом h1 «Заявка такая-то».

- Статус указывается с ролью, роль склоняется. Пример: «На согласовании у руководителя»
- Даты в статусе не пишутся — вся хронология доступна в ходе согласования
- Если в кадровой системе создана сущность, к статусу добавляется примечание в скобках: «(проведено мероприятие)»
